claude-google

교사용 개인 업무 자동화 도구 · A personal automation tool for teachers

claude-google은 선생님이 자신의 컴퓨터에서 실행하는 작은 프로그램입니다. AI 도우미(Claude)가 선생님 본인의 구글 시트·문서·설문지·캘린더·앱스스크립트를 대신 만들고 고칠 수 있게 연결해 줍니다.

무엇을 하나요

  • 수행평가 채점표, 출석부 같은 구글 시트 만들기와 칸 채우기
  • 시트에 붙는 앱스스크립트(자동화 메뉴) 만들기와 고치기
  • 구글 문서·설문지·슬라이드·캘린더 일정 만들기

누가 쓰나요

AI미래교육연구회 연수에 참여한 선생님들이 각자 자기 구글 계정으로 연결해 씁니다. 운영자가 따로 데이터를 모으거나 보관하는 서버는 없습니다.

English

claude-google is a small desktop program that each teacher runs on their own computer. It lets the Claude assistant create and edit the teacher's own Google Sheets, Docs, Forms, Slides, Calendar events and Apps Script projects. There is no central server; no data is collected by the developer.
