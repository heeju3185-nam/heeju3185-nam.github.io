개인정보처리방침

claude-google · 시행일 2026년 11월 1일

1. 어떤 정보에 접근하나요

사용자가 직접 로그인해 허락한 범위 안에서 사용자 본인의 구글 시트, 드라이브, 문서, 슬라이드, 설문지, 캘린더, 앱스스크립트에 접근합니다.

2. 정보는 어디에 저장되나요

로그인 정보(토큰)는 사용자 본인의 컴퓨터에만 저장됩니다. 개발자나 운영자의 서버로 보내지 않으며, 따로 모으거나 보관하지 않습니다.

3. 정보를 어떻게 쓰나요

사용자가 요청한 작업(시트 만들기, 칸 채우기, 스크립트 고치기 등)을 하는 데에만 씁니다. 광고, 판매, 제3자 제공에는 쓰지 않습니다. 구글 API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(Limited Use 요건 포함)을 따릅니다.

4. 연결 끊기와 삭제

언제든 구글 계정 → 서드 파티 앱 및 서비스에서 claude-google 연결을 해제할 수 있습니다. 컴퓨터에 저장된 토큰 파일(token.json)을 지우면 로그인 정보도 함께 지워집니다.

5. 학생 개인정보

학생 정보가 담긴 자료를 다룰 때는 소속 학교와 교육청의 개인정보 보호 지침을 따르고, 가능한 한 이름 대신 번호나 가명을 쓰도록 권장합니다.

Users can revoke access at any time at myaccount.google.com/permissions.
