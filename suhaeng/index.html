A. 빠른 길 — 사본으로 바로 쓰기

1시트 사본 만들기

  1. 위의 📄 시트 사본 만들기를 누릅니다.
  2. 오른쪽 위 프로필이 개인 지메일인지 확인하고 사본 만들기.
  3. 사본 이름을 2학기 국어 수행평가처럼 바꿔 두세요.
사본에는 앱스스크립트 코드까지 같이 복사됩니다. 코드를 직접 붙여넣을 필요가 없어요.

2처음 승인하기 (한 번만)

  1. 사본을 열고 10초쯤 기다리면 위쪽에 메뉴 4개가 생겨요. 안 보이면 F5.
  2. 아무 메뉴나 처음 누르면 «승인 필요» 창이 떠요 → 확인 → 내 지메일 선택
  3. «Google에서 확인하지 않은 앱» → 고급 → (안전하지 않음)으로 이동
  4. 권한 화면에서 모두 선택 → 계속 → 메뉴를 한 번 더 누르세요.
내가 만든(복사한) 스크립트라서 뜨는 경고예요. 이 스크립트는 내 시트와 내 드라이브에만 접근합니다.

3과목별 예시 고르기

  1. 📚 과목별 예시 → 과목별 예시 고르기
  2. 과목 버튼(국어·수학·영어·통합사회·물리학·화학·생명과학·지구과학·기술·가정·한국사·세계사·윤리와 사상·정보) → 예시 → 미리 보기
  3. 이 예시 적용하기 → [정답]·[서술형 기준]·[설정] 평가 이름이 바뀝니다.
탭무엇을 적나
정답단답형: 문항 · 정답 · 인정답(피드백|피이드백처럼 |로) · 배점 · 문제
«문제» 칸은 학생 사이트에 그대로 보여요. 정답 힌트가 들어가지 않게 적으세요.
서술형 기준문항번호 · 문항 · 모범 답안 · 평가 요소 · 배점 · 부분 점수 기준 (요소마다 한 줄, 문항번호는 같게)
예시 모음같은 모양으로 줄을 더 적으면 고르기 창에 바로 나와요. 다 보면 탭 닫기(숨기기)
예시 문항은 연습용이에요. 실제 평가에는 과목 선생님이 검토한 문항·기준을 넣으세요.

4명렬표 넣기

  • [명렬표] 탭: 학년 · 반 · 번호 · 이름 네 칸. 지금은 1학년 1~3반 가짜 명단 75명이 들어 있어요.
  • 학번은 자동으로 5자리가 돼요: 1학년 5반 7번 → 10507
  • 연습할 땐 그대로 두고, 실제로 쓸 때 우리 반 명단을 붙여 넣으세요.

5반 목록 · 반 시트 만들기

  1. 📝 수행평가 → ① 반 목록 불러오기 → [설정] 오른쪽(F~I열)에 반 표가 생겨요.
  2. 내가 들어가는 반에 «내 수업», 지금 제출을 받을 반에 «제출 열기» 체크
  3. ② 내 수업 반 시트 만들기 → 1-1, 1-2 … 탭이 생겨요. 학생 1명 = 1줄
문항을 바꾼 뒤 ②를 다시 누르면 칸이 새 문항에 맞게 바뀌고, 선생님이 적은 최종 점수 · 메모는 남아요.

6Gemini 키 받아 넣기

  1. aistudio.google.com/apikey → 개인 지메일로 로그인 → Create API key → 복사
  2. 시트 [설정] 탭 맨 위 «Gemini API 키» 노란 칸에 붙여넣기 → 칸이 ●●●● 저장됨 (끝 abcd)로 바뀌면 끝
  3. 바로 아래 «Gemini 모델»·«대체 모델» 칸은 ▼ 드롭다운에서 고르면 돼요. [설정] 오른쪽 작은 표에 모델별 특징과 추천 조합이 있어요.
키는 칸에 남지 않고 내 계정에만 저장돼서 시트를 공유해도 보이지 않아요. 시트를 같이 쓰는 선생님은 각자 자기 키를 붙여넣으면 돼요. 칸이 ●●●●로 안 바뀌면 메뉴 📝 수행평가 → 🔑 Gemini 키 넣기 (창으로)를 쓰세요.

7학생 사이트 배포

  1. 확장 프로그램 → Apps Script
  2. 오른쪽 위 배포 → 새 배포 → 톱니 ⚙ → 웹 앱
  3. 실행 사용자 나 · 액세스 권한 모든 사용자 → 배포 → 권한 허용
  4. 배포 완료 창의 웹 앱 URL(끝이 /exec)을 복사 → 시트 [설정] «학생 사이트 주소» 칸에 붙여넣기
  5. 🌐 학생 사이트 → 학생 사이트 주소 · QR → 주소와 QR을 학생에게
QR은 [설정] «학생 사이트 주소» 칸의 주소로 만들어져요. 사본에 다른 주소가 이미 들어 있다면 꼭 내 /exec 주소로 바꾸세요. 그대로 두면 우리 학생 답안이 다른 선생님 시트로 들어가요.
나중에 코드를 고쳤다면 새 배포가 아니라 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포. 그래야 주소가 그대로예요.

8학생처럼 제출해 보기

  1. 아래 📦 학생 답안 예시를 내려받아 압축을 풀고, 3단계에서 고른 과목 폴더를 여세요.
  2. 휴대폰으로 QR → 처음 가입: 파일 이름의 학번·이름으로 (예: 10101 · 최하은) · 비밀번호 · 비밀번호 찾기 질문과 답
  3. 문제 목록 확인 → 📷 답안지 사진 고르기로 그 학생의 답안 사진(jpg)을 올리고 → 제출
  4. 사진 대신, 또는 사진과 함께 «글로 쓰기 (선택)» 칸에 답을 적어 낼 수도 있어요. 글은 반 탭 «글» 칸에 들어가요.
  5. 시트 1-1 탭에서 그 학생 줄이 ❌ → ✅로 바뀌는지 보세요.
  6. 로그아웃 → 비밀번호를 잊었어요 → 학번·이름 → 질문에 답 → 새 비밀번호
📦 학생 답안 예시 13과목 내려받기 (zip · 10MB)
과목마다 손글씨 사진 2장(잘 쓴 학생 / 실수가 섞인 학생) + 스캔 PDF 1개. 파일 이름 = 학번_이름_예시이름이고 학번·이름은 [명렬표]의 연습용 학생이에요. 파일 이름의 예시를 [과목별 예시 고르기]에서 먼저 적용한 뒤 채점하세요. 무엇을 일부러 틀리게 썼는지는 zip 안 00_안내.txt에 있어요. PDF는 학생 사이트 대신 🔎 OCR 도구로 읽어 보기에 좋아요.
명렬표에 있는 학생만 가입돼요. 답도 잊은 학생은 «선생님께 초기화 요청» → [학생계정] 탭에서 그 학생의 비밀번호 칸을 지우면 다시 가입할 수 있어요.

9AI 채점하고 확인하기

  1. 📝 수행평가 → ④ AI 채점 시작 — 제출 ✅이고 상태가 빈 학생만 채점해요.
  2. 단답 결과: ⭕ 정답 · 🔺 비슷함(0점, 선생님 확인) · ❌ 오답. 칸 메모에 «읽은 답»
  3. 서술 N번: 점수. 칸에 마우스를 올리면 읽은 글과 요소별 근거
  4. 확인 후 노란 최종 점수 칸은 선생님이 직접
  5. 다시 하고 싶은 학생 줄 선택 → ⑤ 선택한 학생 다시 채점
[설정] 칸쓰임
생각 수준low 빠름 · high 꼼꼼함
피드백 만들기끄기(기본, 빠름) · 켜기면 피드백 초안도 — 대신 느려져요

10점수 공개 · 미제출 명단

  • [설정] 반 표의 «점수 공개» 체크 → 학생 사이트에 최종 점수와 피드백이 보여요. (AI 초안은 학생에게 안 보여요)
  • ③ 미제출 명단·안내문 → [미제출] 탭에 반별 명단과 조회 때 읽어 줄 안내문
  • 마감: [설정] 마감일이 지나면 자동으로 막히고, 제출 받기를 끄기로 하면 바로 막혀요.

11OCR 도구 (Gemini · 클로바)

  • 🔎 OCR 도구 → 파일 올려서 글자 읽기: 사진·PDF 여러 개 → [OCR스캔] 탭에 글자가 쌓여요. 창 맨 위에서 엔진 선택
  • 드라이브 폴더 글자 읽기: 폴더 주소를 붙이면 안 읽은 파일만 읽어요. [설정] «OCR 엔진»을 따라요.
  • 클로바를 쓰려면 🟢 클로바 OCR 연결 → 네이버 클라우드 CLOVA OCR 도메인의 APIGW Invoke URL과 Secret Key
클로바는 jpg·png·pdf만 읽어요. 아이폰 HEIC 사진은 파일 올리기 창을 쓰면 자동으로 jpg로 바뀌어요.
B. 만들어 보는 길 — 클로드 코드에 붙여넣는 프롬프트

B0⚡ 간단 버전 — 3줄로 시작하기

완벽한 프롬프트를 쓰려 하지 말고, 3줄로 시작해서 대화하며 고치세요. B1~B5는 이 3줄을 하나씩 키운 모습이에요.

💬 이것만 복사하면 시작돼요
구글 시트로 수행평가 채점 도우미를 만들어 줘.
학생은 휴대폰으로 답안지 사진을 찍어 내고, 시트에 적은 정답과 채점 기준으로
메뉴 하나만 누르면 Gemini가 단답형·서술형 초안 점수를 매기게 해 줘.
이렇게 바꿔 보세요예시
과목·문항“[중2 과학] [광합성] 서술형 2문항으로”, “단답형만 10문항”
제출 방법“사진 대신 글로도 내게”, “사진은 최대 6장까지”
학생 관리“명렬표에 있는 학생만 가입”, “반별로 탭을 나눠 줘”
채점 방식“비슷한 답은 🔺로 표시만”, “표현이 달라도 뜻이 맞으면 인정”
결과“피드백 초안도 써 줘”, “최종 점수는 내가 적고 체크하면 학생에게 공개”
🗣️ 막히면 — “느려”, “학생이 헷갈려 해”처럼 느낀 그대로 말하고, 오류 창은 캡처해서 붙이고, 한 번에 하나씩 요청하세요.

B1채점 시트 만들기

구글 MCP를 붙인 클로드 코드(패들렛 3~4장)에서 씁니다. [ ] 부분만 내 과목으로 바꾸세요.

💬 클로드에게 붙여넣기
구글 시트로 수행평가 채점 시트를 만들어줘. 제목은 [고1 통합사회 수행평가 채점]이야.
탭은 안내 / 채점기준 / 답안 / 설정 네 개.
- 채점기준: 문항번호 | 문항 내용 | 모범 답안 | 평가 요소 | 배점 | 채점 기준(부분 점수). 평가 요소마다 한 줄, 같은 문항은 문항번호를 같게.
- 답안: 번호 | 이름(가명) | 문항번호 | 답안 이미지 링크 | 답안 텍스트 | 상태 | 읽은 글자 | 요소별 점수 | AI 점수 | 만점 | 최종 점수 | 선생님 메모
- 설정: 항목 | 값 | 설명 (과목·학년, Gemini 모델, 생각 수준, 엄격도)
[인권과 헌법] 단원으로 서술형 2문항 예시와 가짜 학생 5명 답안(잘 쓴 답, 반만 맞은 답, 틀린 답 섞어서)을 넣어줘. 다 되면 링크 줘.

B2Gemini 채점 버튼 (앱스스크립트)

💬 클로드에게 붙여넣기
방금 만든 시트에 연결된 앱스스크립트를 만들어줘.
- 시트를 열면 «AI 채점» 메뉴: ① Gemini API 키 넣기 ② 채점 시작 ③ 선택한 줄 다시 채점
- 키는 시트 칸이 아니라 사용자 속성(PropertiesService.getUserProperties)에 저장
- 답안 이미지 링크가 있으면 드라이브에서 사진을 읽어 Gemini에 같이 보내 손글씨를 읽고 채점, 없으면 답안 텍스트로 채점
- Gemini는 JSON으로 요소별 점수와 15자 이내 근거만 돌려주게 하고, 배점보다 높으면 배점까지만 인정
- 여러 줄은 UrlFetchApp.fetchAll로 8개씩 한꺼번에 보내고, 생각 수준은 [설정] 탭 값(low) 사용
- 6분 제한 전에 멈추고 남은 줄은 1분 뒤 트리거로 이어서 채점
- «채점 중»이 10분 넘게 남아 있으면 멈춘 것으로 보고 다시 채점
모델 이름은 [설정] 탭에서 읽어. 코드는 시트에 바로 올려줘.
«모델을 찾을 수 없다(404)» 오류가 나면 오류 메시지에 나온 새 모델 이름을 [설정] 탭에 넣으면 돼요.

B3학생 제출 웹앱

💬 클로드에게 붙여넣기
같은 앱스스크립트에 학생 제출용 웹앱(doGet)을 추가해줘.
- 학생은 로그인 없이 휴대폰에서 열고, 번호·이름·제출 코드를 넣고 답안지 사진을 최대 6장 찍어 제출 (사진 대신 또는 함께 «글로 쓰기» 칸에 글로도 낼 수 있게)
- 사진은 올리기 전에 휴대폰에서 긴 변 1600px JPEG로 줄여서 보내기
- 사진은 내 드라이브 «수행평가 제출» 폴더에 저장하고, [답안] 탭에 채점기준의 문항 수만큼 줄을 만들어 링크를 넣어줘
- 같은 번호로 다시 내면 그 줄의 사진을 바꾸고 이전 채점 결과를 지우고 메모에 «재제출»
- 여러 명이 동시에 내도 섞이지 않게 LockService 사용
- 사진 한 장에 여러 문항이 있으니 채점할 때 «N번 문항 답만 찾아 채점»하게 프롬프트도 고쳐줘
배포는 내가 할게: 배포 → 새 배포 → 웹 앱 / 실행: 나 / 액세스: 모든 사용자.

B4명렬표 · 반별 탭 · 학생 계정

💬 클로드에게 붙여넣기
채점 시트를 반별로 바꾸고 싶어.
- [명렬표] 탭(학년·반·번호·이름)에서 학번 5자리(1학년 5반 7번 → 10507)를 만들고, 가짜 명단 1학년 3개 반 × 25명을 넣어줘
- 메뉴 ① 반 목록 불러오기: [설정] 탭 오른쪽(F열부터)에 반 | 내 수업 | 제출 열기 | 점수 공개 체크박스 표
- 메뉴 ② 내 수업 반 시트 만들기: 반마다 탭(1-1 …), 학생 1명 = 1줄 (학번 | 이름 | 제출 ✅/❌ | 사진 | 상태 | 단답 결과 | 서술 N번 | AI 합계 | 최종 점수 …)
- 웹앱은 학번·이름·비밀번호로 가입(명렬표에 있는 학생만), 비밀번호와 «비밀번호 찾기 질문»의 답은 암호화해서 [학생계정] 탭에 저장
- 비밀번호를 잊으면 가입 때 고른 질문에 답해서 새 비밀번호로 바꾸기, 5번 틀리면 잠깐 잠그기
- 제출하면 [제출] 탭에 기록하고 반 탭을 ❌ → ✅, «점수 공개»가 켜진 반은 학생이 최종 점수를 볼 수 있게
- 단답형은 [정답] 탭(정답·인정답 |)과 비교해 ⭕ / 🔺(비슷함, 0점) / ❌
- 메뉴 ③ 미제출 명단·안내문

B5과목별 예시 · OCR 메뉴

💬 클로드에게 붙여넣기
메뉴를 서로 부딪히지 않게 4개로 나눠줘: 📚 과목별 예시(맨 왼쪽) / 📝 수행평가 / 🌐 학생 사이트 / 🔎 OCR 도구.

- 📚: [예시 모음] 탭(과목 | 예시 이름 | 구분 | 문항번호 | 문항 | 정답·모범 답안 | 인정답 | 평가 요소 | 배점 | 기준)에서 과목 버튼 → 예시 → 미리 보기 → 적용하는 창. 탭 열기 / 닫기(숨기기)도.
  고등학교 [국어, 수학, 영어, 통합사회, 물리학, 화학, 생명과학, 기술·가정, 한국사, 세계사, 윤리와 사상] 예시를 과목마다 2개씩 만들어줘.
- 🔎: 사진·PDF 여러 개를 올리거나 드라이브 폴더 주소를 넣으면 글자를 읽어 [OCR스캔] 탭에. 엔진은 Gemini 또는 네이버 클로바 OCR(Invoke URL + Secret Key) 중 선택.
